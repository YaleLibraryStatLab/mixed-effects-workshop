# Yale StatLab: Mixed-Effects Models

Materials for the Yale Library **StatLab** workshop on mixed-effects models. This workshop is taught in R. We cover the difference between fixed and random effects, main strategies for estimation, and some general insights on best practices. 

Taught by Cole Brookson, MSc — Yale Library | StatLab.
Free for all Yale affiliates: [library.yale.edu/statlab](https://library.yale.edu/statlab)

## Getting set up 


1. [Install or update R](https://cran.r-project.org) (version 4.2 or newer). You'll also want an editor. [RStudio](https://posit.co/download/rstudio-desktop/) or Positron both work well.

2. Download the workshop materials:
   If you use git: `git clone git@github.com:YaleLibraryStatLab/mixed-effects-workshop.git`
   If not: click the green "Code" button, then "Download ZIP", and unzip it somewhere easy to find.

3. Open the workshop folder as a project.
   In RStudio, double-click `mixed-effects-workshop.Rproj`. In Positron or VS Code, open the whole folder.

4. Run the setup script.
   Open `setup.R` and click "Source" (or type `source("setup.R")` in the console). It will install the packages we need and run a quick test.
