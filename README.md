# Yale StatLab: Mixed-Effects Models

Materials for the Yale Library **StatLab** workshop on mixed-effects models. This workshop is taught mainly in R, with a follow-along component for Julia and Python provided. We cover the difference between fixed and random effects, main strategies for estimation, and some general insights on best practices. 



Taught by Cole Brookson, MSc — Yale Library | StatLab.
Free for all Yale affiliates: [library.yale.edu/statlab](https://library.yale.edu/statlab)
